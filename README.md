## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/nangyal-khan-portfolio.git
```

### 2. Enter the project

```bash
cd nangyal-khan-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The website will normally be available at:

```text
http://localhost:5173
```

---

## 🏗️ Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The generated production files are usually placed inside:

```text
dist/
```

## 🔐 Environment Variables

If you enable external services such as Resend or other APIs, store private credentials in environment variables.

Example:

```env
RESEND_API_KEY=your_api_key
CONTACT_EMAIL=nangyalkhan0988@gmail.com
RESEND_EMAIL_FROM=your_verified_sender
```

### Security

**Never commit API keys or private credentials to GitHub.**

Add your environment file to `.gitignore`:

```text
.env
.env.local
.env.*.local
```
